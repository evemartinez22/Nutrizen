# Nutrizen - Proyecto Web (Nutrición Consciente)

Sitio web enfocado en la nutrición consciente, talleres de cocina saludable y bienestar integral, desarrollado como pre-entrega académica.

## Características Principales:
- **Estructura Semántica:** Uso correcto de etiquetas HTML5 (`header`, `nav`, `main`, `section`, `footer`).
- **Diseño Responsivo:** Implementación de Flexbox, CSS Grid y Media Queries.
- **Formulario de Contacto:** Funcional e integrado mediante Formspree.
